---
title: Accessibility statement
---
We want as many people as possible to be able to use this website. You should
be able to:

- change colours, contrast levels and fonts using your browser or device settings
- zoom in up to 400% without the text spilling off the screen
- navigate the whole website using just a keyboard
- use the website with a screen reader

## How accessible this website is

We aim to meet the [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/)
at level AA.

We know some parts of the website are not fully accessible:

- **Maps** cannot be fully used without sight or a mouse. Every project shown
  on a map is also listed by name on the [Projects](/projects/) page and next
  to the map, so you can reach the same information without using the map.
- **PDF documents**, such as project reports, may not be fully accessible
  to screen reader software.

## Reporting accessibility problems

If you find a problem, or need information in a different format, please
[contact us](/contact/).

## Preparation of this statement

This is a demonstration statement, prepared on 1 November 2026. The website has
not yet been tested by an independent auditor.
