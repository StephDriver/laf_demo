Many disabled people ride adapted cycles, such as handcycles, trikes and
tandems. Footpaths are not open to cyclists, and stiles, kissing gates and
narrow or uneven surfaces can also stop adapted cycles using a route.

This project looks at Fingringhoe Footpath 3 in Colchester district, shown
highlighted in yellow on the map. It is about 180 metres long. We want to find out:

- who would like to use the path by cycle, and why
- what the surface, width and any barriers on the path are like now
- what would have to change, legally and physically, for adapted cycles to use it

Add progress notes as updates, and use the map to see where the path is.
