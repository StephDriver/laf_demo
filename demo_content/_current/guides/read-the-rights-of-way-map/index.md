---
title: How to use the rights of way map
summary: Find a path, see what type it is, and find a project in your area.
---
Our [map](/map/) shows public rights of way and the areas covered by our
projects.

## Find a place

1. Zoom in using the **+** button, or by scrolling or pinching.
2. Drag the map to move around.

## See what type of path it is

Each type of path has its own colour and style. Select a line to see its type,
its path number and its parish.

The types are footpath, bridleway, restricted byway and byway open to all
traffic. The [glossary](/glossary/) explains who can use each one.

## Show or hide layers

Use the layers button on the map to switch paths, project areas and markers on
or off. This is useful when the map is busy.

## Find a project

Project areas are shaded. Select one to see a short description and a link to
the project page. You can also search the list beside the map by project name.

## Things to know

- The map is a guide only. It is **not** the legal Definitive Map. To check the
  legal status of a path, see [how to check if a path is public](/guides/check-if-a-path-is-public/).
- The map is updated only occasionally, so very recent changes may be missing.
